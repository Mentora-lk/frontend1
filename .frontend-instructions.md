# Frontend Modifications Required - Student Community Fix

## Issue
Student community pages show "404 Route not found" error when trying to fetch posts/feed.

**Error:** `GET http://localhost:5000/api/student/communities/1/posts` returns 404

## Root Cause
The backend endpoint `/api/student/communities/{id}/posts` (and `/feed`) do not exist. Currently only `/api/tutor/communities/{id}/posts` exists.

## Solution Options

### Option 1: Use Tutor Endpoint Pattern (Recommended)
Students should fetch posts from the same endpoint as tutors since both are communities.

**Modification needed in `src/services/studentCommunityService.ts`:**

Change this:
```typescript
export const getCommunityFeed = async (communityId: string | number) => {
    return apiCall<any>(`/api/student/communities/${communityId}/feed`, {
        method: "GET",
        headers: getAuthHeaders()
    });
};
```

To this (reuse tutor endpoint with student auth headers):
```typescript
export const getCommunityFeed = async (communityId: string | number) => {
    return apiCall<any>(`/api/tutor/communities/${communityId}/posts`, {
        method: "GET",
        headers: getAuthHeaders()
    });
};
```

**Why this works:** 
- The tutor endpoint returns posts with media data
- Student authentication headers ensure students only see posts from communities they're enrolled in
- No backend changes needed
- Reuses proven working endpoint

### Option 2: Create Backend Endpoint
If you want a separate student endpoint, backend needs to create:
```
GET /api/student/communities/{id}/posts
```

This endpoint should:
- Check student is member of community
- Return array of posts with fields: `id, type, content, media_url, author, created_at, etc.`
- Support the same post types: `text, image, video, pdf, poll`
